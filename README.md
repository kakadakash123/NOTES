
# Cybersecurity Notes

This repository contains concise cybersecurity notes, practical concepts, tool references, and security testing methodologies developed during hands-on learning and project work.

## Topics Covered

* OWASP Top 10
* OWASP API Security Top 10
* Burp Suite
* SQL Injection
* Cross-Site Scripting (XSS)
* Cross-Site Request Forgery (CSRF)
* Session Management
* Web Application Security Testing
* Broken Authentication
* Broken Access Control
* SSRL
* CORS
  

## Purpose

The goal of this repository is to maintain structured notes for quick revision, interview preparation, and continuous learning in cybersecurity.
